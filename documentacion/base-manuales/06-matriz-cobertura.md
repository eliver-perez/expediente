# AIBID — Matriz de cobertura

**Fecha de elaboración: 2026-10-09.** Actualización de la base elaborada el 8 de octubre; nombres y procedimientos contrastados con la transición de producción. Base de trabajo para los futuros manuales; no es un manual final.

## Interpretación

La matriz incluye una fila por cada una de las **127 FUN**. PAN se refiere a superficies concretas y CAP a escenas requeridas. Una FUN puede tener prueba parcial sin que todo su procedimiento/platforma esté certificado. **Ninguna fila se declara manual completamente terminado**: esta entrega es base de investigación. No se confunde cantidad de filas con calidad/evidencia.

- **Inventariado:** campos, ubicación, permiso, procedimiento y fuente registrados.
- **Verificado en pruebas (parcial):** escenario previo PASS citado en 01; no observación actual de UI.
- **Listo para redactar texto base:** código y escenario permiten redactar un borrador con las reservas indicadas; revisiones visuales/capturas y VAL continúan abiertas. No significa listo para publicación del manual completo.
- **Pendiente de validar:** acciones nativas/plataformas/external proveedor o ambigüedad explícita; mantener advertencia al redactar.

Los tres manuales futuros no se han generado. “Procedimiento” pide pasos de usuario/administrador; “Explicación” pide arquitectura/modelos/operación. Capturas pendientes no autorizan inventarlas.
