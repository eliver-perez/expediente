# AIDEX 1.0.0 — instalación interna de prueba en Windows 11 AMD64

Este ejecutable es para pruebas internas. No está firmado comercialmente ni constituye una distribución oficial. El CLUF incluido es un **borrador pendiente de revisión jurídica**; la primera ejecución pide su aceptación antes de permitir utilizar bibliotecas y expedientes.

1. Copia `AIDEX-1.0.0-Windows-amd64.exe` y `SHA256SUMS` al equipo Windows 11 de 64 bits. Compara el SHA-256 del ejecutable con la línea correspondiente de `SHA256SUMS` usando `Get-FileHash .\AIDEX-1.0.0-Windows-amd64.exe -Algorithm SHA256` en PowerShell.
2. Ejecuta el instalador y acepta la elevación de Windows. En una instalación nueva, confirma el puerto TCP propuesto (`18090`) o elige otro libre. En una actualización se conserva el puerto ya configurado. Si detecta un servicio `AIBID`, `AIBIDTest` o `AIBID-Test`, se detendrá antes de alterar AIDEX. Desinstala la versión anterior con **su propio** desinstalador conservando sus datos; no borres manualmente carpetas de documentos ni `%ProgramData%`.
3. Desde Inicio abre **AIDEX → Configurar AIDEX** como administrador. Crea la cuenta administradora; la contraseña requiere al menos seis caracteres. El asistente comprueba PDF/OCR, inicia el servicio y abre el navegador en el puerto elegido.
4. Inicia sesión. Lee el CLUF provisional, marca la casilla de aceptación y continúa. Comprueba que, antes de aceptarlo, las bibliotecas y API documentales permanecen bloqueadas. Después abre **Licencia** y activa mediante un código autorizado o genera una solicitud `.licreq` para el procedimiento offline. La licencia no viene incluida en el instalador.
5. Verifica el acceso mediante el icono **AIDEX** del Escritorio o Inicio, que abre el navegador sin elevación. Prueba con documentos sintéticos, la búsqueda, una descarga y, si corresponde, OCR. Para vistas previas de Word/Excel instala LibreOffice aparte; la extracción y búsqueda de esos formatos no lo requieren.
6. Para probar actualización, vuelve a ejecutar **este mismo instalador** sobre la instalación AIDEX 1.0.0. Debe conservar `%ProgramData%\AIDEX`, la identidad local y los documentos. No instales por encima de una versión distinta si el preflight la rechaza.
   Para cambiar un puerto local mientras el servicio funciona, entra en **Ajustes → Acceso y red** como administrador. Si el puerto está ocupado y el sitio no inicia, abre **Inicio → AIDEX → Configurar servidor AIDEX** con elevación; muestra el puerto actual, aplica otro, actualiza la regla propia del firewall y recupera el anterior si falla. Los cambios de puerto con acceso LAN en Windows requieren esta herramienta elevada para modificar el firewall. El acceso directo **AIDEX** abre el puerto vigente. Comprueba el puerto con `Get-NetTCPConnection -State Listen -LocalPort <puerto>` y prueba la URL desde otra PC si habilitaste LAN.
7. Para desinstalar, usa **Aplicaciones instaladas → AIDEX → Desinstalar**. La opción de eliminar datos internos viene **desmarcada**; deja esa opción sin marcar para conservar base, licencia local, configuración y documentos. Incluso si se marca y se confirma por segunda vez, los documentos físicos originales y las cargas privadas permanecen en sus rutas. La desinstalación local no libera una plaza del servidor: desactiva la licencia desde AIDEX antes de retirar el equipo si necesitas trasladarla.

En caso de error, conserva una captura del mensaje y el registro temporal indicado por el instalador. No compartas códigos comerciales, archivos privados de identidad ni el contenido de `%ProgramData%\AIDEX` en reportes públicos. Las pruebas nativas del servicio, ACL, firewall y OCR deben hacerse en Windows; la compilación cruzada en macOS no sustituye esa comprobación.
